# Test Generator - Генератор тестов на Django

## Описание проекта

Проект представляет собой веб-приложение для создания, прохождения и анализа результатов тестов. Реализованы все основные функции из оригинального консольного приложения на SQLite, перенесенные в Django-версию.

## Основные возможности

- 📝 Создание и редактирование тестов
- ❌ Удаление тестов
- ✏️ Добавление вопросов с вариантами ответов
- ✅ Отметка правильных ответов
- � Прохождение тестов пользователями
- 📊 Просмотр результатов
- 📅 Отображение дат с учетом временной зоны

## Технологический стек

- Python 3.9+
- Django 4.0+
- SQLite (по умолчанию)
- Bootstrap 5 (для интерфейса)
